# excel-data-analyst-journey
30-day Excel learning journey for Data Analyst &amp; HR roles
## What's in this repo
This is a hands-on Excel learning journey aimed at Data Analyst and HR roles.

### Week 1 — Foundations
- Cell referencing (relative vs absolute)
- Sorting, filtering, freeze panes
- SUM, AVERAGE, COUNT, COUNTA
- COUNTIF, SUMIF
- Text functions (LEFT, RIGHT, MID, TRIM, CONCATENATE)
- Data validation & dropdown lists

**Files:**
- `Week1_Project_HR.xlsx` — HR employee data project combining all Week 1 concepts
- `Week1_Project_DataAnalyst.xlsx` — Sales data project combining all Week 1 concepts
